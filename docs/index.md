# Bleu.js

`pip install bleu-js` installs the API client and CLI for `https://api.bleujs.org`. Optional extras add ML, quantum, deep learning, and a self-hosted server.

Bleu OS was removed from this project. Older PyPI release pages that describe it are historical.
