# Bleu.js docs

The canonical project page is the [root README](../README.md).

`pip install bleu-js` installs the API client and CLI. Optional extras add ML (`[ml]`), quantum (`[quantum]`), deep learning (`[deep]`), and a self-hosted server (`[server]`). The hosted API is `https://api.bleujs.org`.

Bleu OS was removed from this project. Older PyPI release pages that describe it are historical.
